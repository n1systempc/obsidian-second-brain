# Importar no Claude

[Baixe obsidian.zip](https://raw.githubusercontent.com/n1systempc/obsidian-second-brain/main/downloads/obsidian.zip) e envie o ZIP fechado em **Customize → Skills → + → Create skill → Upload a skill**. Depois, ative a skill.

Para criar o vault no computador, abra o Claude Code dentro do projeto e execute `/obsidian install`.
